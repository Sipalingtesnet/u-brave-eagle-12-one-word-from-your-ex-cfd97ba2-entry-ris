## The entry

`main.py` writes one word to `/output/entry.txt` and nothing else.

```
harmless
```

An ex says it kindly, which is the joke. It arrives as a compliment — nothing
to fear — and then the second half lands: nothing to lose either, nothing to
want, no argument worth having. `safe` would flatter you. `harmless` is a
verdict handed over with a shrug. That is why it stings, and why it is true.

## Run it

Python 3.13 (any 3.x works). No dependencies, no network.

```sh
python3 main.py
cat /output/entry.txt   # harmless
```

UTF-8, eight bytes, no trailing newline.
